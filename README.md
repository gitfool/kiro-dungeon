# Kiro Dungeon

[![License](https://img.shields.io/github/license/gitfool/kiro-dungeon?color=blue&label=License&logo=github)](LICENSE)

A playground for [Kiro](https://kiro.dev), including [steering](https://kiro.dev/docs/steering), agent [skills](https://kiro.dev/docs/skills) and [powers](https://kiro.dev/docs/powers).

## Content

Each is a Kiro power; see its subdirectory README for install and usage details.

| Name | Description |
| --- | --- |
| [aotw-dotnet-skills](aotw-dotnet-skills/README.md) | [Aaronontheweb/dotnet-skills](https://github.com/Aaronontheweb/dotnet-skills) plugin; C#, Akka.NET, Aspire, testing, and performance skills |
| [chrome-devtools](chrome-devtools/README.md) | [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp) plugin; Chrome automation, debugging, and performance skills with the chrome-devtools MCP server |
| [dotnet-diag](dotnet-diag/README.md) | [dotnet/skills](https://github.com/dotnet/skills) plugin [dotnet-diag](https://github.com/dotnet/skills/tree/main/plugins/dotnet-diag); .NET diagnostics and performance skills |
| [dotnet-msbuild](dotnet-msbuild/README.md) | [dotnet/skills](https://github.com/dotnet/skills) plugin [dotnet-msbuild](https://github.com/dotnet/skills/tree/main/plugins/dotnet-msbuild); MSBuild skills and binlog MCP server |
| [dotnet-test](dotnet-test/README.md) | [dotnet/skills](https://github.com/dotnet/skills) plugin [dotnet-test](https://github.com/dotnet/skills/tree/main/plugins/dotnet-test); test execution, generation, and quality skills |
| [dotnet-test-migration](dotnet-test-migration/README.md) | [dotnet/skills](https://github.com/dotnet/skills) plugin [dotnet-test-migration](https://github.com/dotnet/skills/tree/main/plugins/dotnet-test-migration); .NET test framework and platform migration skills |
| [dotnet-upgrade](dotnet-upgrade/README.md) | [dotnet/skills](https://github.com/dotnet/skills) plugin [dotnet-upgrade](https://github.com/dotnet/skills/tree/main/plugins/dotnet-upgrade); .NET migration skills |
| [pstack](pstack/README.md) | Cursor plugin [pstack](https://github.com/cursor/plugins/tree/main/pstack) skills and principles |
| [windbg](windbg/README.md) | [windbg-mcp](https://github.com/glslang/windbg-mcp) server and debugging skill |
